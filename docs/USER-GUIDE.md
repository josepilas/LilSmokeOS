The previous version of this page described the early J-job design, including
unverified SF3000/GB350 assumptions, an obsolete partition layout and unsupported
boot-time/FPS claims. Those are not instructions or guarantees for the current
SEGAM-M8-V6.0 image. Historical text remains available in Git history; the
[Pre-Alpha manual](pre-alpha-0.0.1/user-manual.md) is also preserved separately.

Use Settings -> Power Off and wait for its completion indication before
disconnecting power. Never assume a black screen alone proves safe shutdown.
