# Alpha-0.0.1

LilSmokeOS by José Pilas. The entire original authored OS external tree,
including C++ UI, shell services, Buildroot integration and SDK/API, is public
under MPL-2.0. Dependencies and upstream fork modifications retain their own
licenses. Daedalus-LilSmoke and custom Mupen-LilSmoke experiments are excluded;
ordinary upstream Mupen64Plus support is preserved.

No ROM, BIOS collection, stock export, extracted game data or private capture
is included in source. The inventory/exclusion/audit reports explain missing
artwork and external build dependencies. This is not blanket relicensing or
complete binary redistribution clearance.

The image is assembled and verified separately using verified runtime binaries
and new version/license/docs. Do not infer a new physical cold-boot test from
source staging, host tests or the older Pre-Alpha image. Alpha geometry,
SHA-256 and test results belong to its final independent image report.

Tested lineage: SEGAM-M8-V6.0, stock V1.0.0 2024-12-05, HCSEMI MIPS/128 MiB.
This is not universal M8/SF3000/GB350 firmware. Back up storage, use a spare
card and read installation/known limitations before flashing.
Use Settings -> Power Off and wait for completion before disconnecting power.
