# Changelog

## 0.0.1

First public packaging/source release of Undertale-LilSmoke. The qualified
private internal 0.1.0 engine is unchanged, including its diagnostic version.

- Asset-free package with on-device preparation, cache reuse, input and SDL audio.
- Self-contained offline source subset and dependency sources/notices.
- Explicit AGPL runtime / MPL independent-tool boundaries and contributor credits.
- Same-release source offer, source manifest and package privacy audit.

No gameplay rebuild, new engine fixes, whole-game qualification or new physical
performance result is implied by this release-number change.
